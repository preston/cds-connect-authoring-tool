**IMPORTANT**: ANTLR4 versions after 4.8.0 generate code that uses ESM style imports instead of Common JS requires statements. Since the JavaScript runtime must match the version of ANTLR4 used to generate the classes, we are only using the the antlr4 JavaScript from 4.13.2 and later.
